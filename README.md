**Примечания:**

1.  **Доступ в России:** "Да" означает, что сервис доступен без VPN на момент проверки. "С ограничениями" может означать проблемы с оплатой подписки из РФ или другие потенциальные сложности.
2.  **Формат скачивания:** Указаны основные форматы. Доступность конкретных форматов (особенно высокого разрешения, векторных или интерактивных) часто зависит от платного тарифа. Бесплатные тарифы часто добавляют водяной знак (брендинг). N/A означает, что сервис не предназначен для прямого скачивания файлов в традиционном понимании (библиотеки кода, агентства, ресурсные сайты, интерактивные веб-платформы).
3.  **Ценовая политика:** Большинство SaaS-сервисов работают по модели Freemium (есть бесплатный и платные тарифы). Уточняйте актуальные ограничения бесплатных тарифов на сайтах сервисов.
4.  **Adobe Express (Spark):** Сам сервис доступен, но могут быть проблемы с оплатой Premium-подписки из России картами российских банков.
